# Fluorite Fork

Full-colour Python 3 neon lightning-fork arcade for [ElbowOS](https://x.com/ElbowOS).

Steer a descending bolt across five neon traces. Fork onto gold-lime **fluorite orbs** for charge. Magenta **void spines** drain you.

Left / Right (or A / D) forks the bolt. R resets. ESC quits.

## Play

```
pip install -r requirements.txt
python3 fluorite_fork.py --play
```

## Record a 9:16 reel

```
python3 fluorite_fork.py --record
```

Writes a 1080x1920 h264 clip (15s @ 30fps) with title, score, and `x.com/ElbowOS` burned into the frames.
